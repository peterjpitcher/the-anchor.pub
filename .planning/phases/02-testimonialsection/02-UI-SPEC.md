## Variant-Specific Layout Contracts

### Variant: `full` (COMP-02)
- Outer wrapper: `section-spacing` class at call site, `bg-anchor-bg-card border-b border-anchor-gold/15`
- Container: full-width `Container` primitive
- Heading: `text-2xl font-bold text-anchor-cream-text` — text "What Our Guests Say" (default, overridable via `title` prop)
- Subheading: `text-sm text-anchor-cream-text/60` — e.g. "From Google Reviews" (overridable via `subtitle` prop)
- Grid: `grid md:grid-cols-2 lg:grid-cols-3 gap-6 mt-8`
- Card: `Card` primitive (`bg-anchor-bg-card rounded-none border border-anchor-gold/20 p-6`)
- Star row: `flex gap-0.5 mb-3` — loop over `rating` number (default 5), aria-label
- Quote: `text-base italic text-anchor-cream-text/80 mb-3` — component adds opening/closing curly quotes
- Author + source: `text-sm text-anchor-cream-text/50`

### Variant: `compact` (COMP-03)
- Outer wrapper: no enforced background — inherits page context; call site applies section class
- Layout: `flex gap-4 overflow-x-auto pb-4` — horizontal scroll strip
- Each card: `min-w-[280px] max-w-[320px]` — fixed width prevents collapse in scroll context
- Card body: same Card primitive, reduced padding `p-4`
- No section heading/subheading in compact variant
- Quote truncated to 3 lines max: `line-clamp-3`
- Stars and attribution displayed same as full variant

### Variant: `pull-quote` (COMP-04)
- Outer wrapper: `bg-anchor-bg-raised border-b border-anchor-gold/15` — Section primitive with `spacing="md" container containerSize="md"`
- Inner: `max-w-2xl mx-auto text-center`
- Opening mark: `&ldquo;` — large decorative; component renders it, caller does NOT include quotes in `quote` prop
- Quote body: `text-2xl text-anchor-cream-text/80 italic leading-relaxed`
- Attribution: `mt-4 text-sm text-anchor-cream-text/50` — format: "{Author}, {source}, rated {rating}/5"
- Stars: omitted in pull-quote variant (rating shown in attribution text only)
- Only the first element of the `reviews` array is rendered; additional items ignored

Source: `app/book-table/page.tsx` line 405 and surrounding pull-quote block.

## Accessibility Contract

- Star row: `<div aria-label="{rating} out of 5 stars">` wrapping `<span aria-hidden="true">★</span>` per star
- No interactive elements in any variant — component is purely presentational
- No focus management required
- Pull-quote uses `<blockquote>` semantic element
- Full/compact card quotes use `<p>` (short testimonials, not extended quotations)
- Color is NOT the sole indicator of any state (no state indicators needed)

---

## Copywriting Contract

No dynamic user-facing copy — all copy is passed via props from the call site. The component does not own any copy.

| Element | Contract |
|---------|----------|
| Section heading | Passed via `title` prop. Default: `"What Our Guests Say"` |
| Section subheading | Passed via `subtitle` prop. Default: `"From Google Reviews"` |
| Quote delimiters | Component renders `&ldquo;` and `&rdquo;` — caller passes raw text without quotes |
| Attribution format | `{author}` — `{source}` (if provided) |
| Rating format (pull-quote) | `rated {rating}/5` appended to attribution line |
| Empty state | Not applicable — if `reviews` array is empty, component renders `null` (silent no-op) |
| Error state | Not applicable — no async operations; static props only |
| Destructive actions | None |

## Component Interface Contract

```typescript
export interface Testimonial {
  quote: string      // Raw text. No surrounding quote marks. Component adds them.
  author: string     // Display name, e.g. "Dave" or "Rachel T."
  source?: string    // e.g. "Google Review" — omit if unknown
  rating?: number    // 1–5. Defaults to 5 if omitted.
}

export interface TestimonialSectionProps {
  variant?: 'full' | 'compact' | 'pull-quote'   // default: 'full'
  reviews: Testimonial[]
  title?: string       // full variant only — default: "What Our Guests Say"
  subtitle?: string    // full variant only — default: "From Google Reviews"
  className?: string   // forwarded to outermost element
}
```

Source: RESEARCH.md data shape section + component interface conventions from HeroBadge.tsx (Phase 1 precedent).
