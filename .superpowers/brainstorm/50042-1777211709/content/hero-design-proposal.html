Smart Hero — Proposed Design

Every hero across all 109 pages gets three layers of intelligence

The Three Layers

1️⃣

Static Content

Title, description, breadcrumbs, image — stays page-specific as it is today. No changes here. This is your SEO layer.

2️⃣

Smart CTAs

Primary + secondary buttons adapt text and link based on time, events, and hours. The position stays fixed — only the label and destination change.

3️⃣

Context Strip

A compact bar at the bottom of every hero showing what's happening right now. Live status, tonight's event, kitchen hours — pulled from API.

Smart CTA Logic — How Buttons Adapt

Priority cascade: highest-priority matching rule wins

Priority Condition Primary CTA Secondary CTA
1 Event happening today "Book [Event Name] Tonight" → event page "Call Us" → tel link
2 Sunday + Sunday lunch available "Book Sunday Lunch" → booking "View Menu" → /sunday-lunch
3 Kitchen currently open "Book a Table" → booking "View Menu" → /food-menu
4 Bar open, kitchen closed "Come for Drinks" → /drinks "Call Us" → tel link
5 Currently closed "Book a Table" → booking "View What's On" → /whats-on
6 Page has its own CTA override Page-specific CTA takes priority (e.g. /private-hire keeps "Enquire Now")

Row 6 is important: pages can opt out and keep their own CTAs. The smart logic is the default, not a mandate.

Context Strip — What's Shown

Compact bar at the hero bottom, up to 3 items separated by dots

🟢 Open now · Bar until 10pm · 🍽️ Kitchen open until 9pm · 🎵 Music Bingo tonight at 8pm
🟢 Open now · Bar until 10pm · Kitchen closed today · 🍺 Monday drinks specials
🔴 Closed now · Opens 4pm today · 📋 Quiz Night this Wednesday
⚠️ Bank Holiday hours today · Bar 12pm–10pm · Kitchen 12pm–7pm · Sunday lunch available

Always 3 slots: Status (open/closed + bar hours) · Kitchen (hours or "closed") · Event/promo (tonight's event, next upcoming event, or special note). If there's no event, the third slot drops and the strip shows just two items.

Consistency Rules — What Every Hero Gets

✓ Always present

  • Title (page-specific)
  • One-line description
  • 1 primary CTA (smart or override)
  • 1 secondary CTA (smart or override)
  • Context strip (3 slots)
  • Breadcrumbs

✗ Removed / not allowed

  • Tag pills (Music Bingo, Quiz Night £3, etc.)
  • Secondary info pills (free parking, 7 min from Heathrow)
  • More than 2 CTA buttons
  • Extra rows of buttons (Pizza Menu, Sunday Roast, etc.)
  • TrustBar component below hero

This means every hero has exactly the same structure. The only thing that varies is the content of the CTAs and strip — driven by live data, not per-page configuration.

Architecture — How It's Built

HeroWrapper (existing — add new props)
  ├── Image layer (unchanged)
  ├── Content layer (title, description, breadcrumbs — unchanged)
  ├── SmartCTAs (new client component)
  │   ├── Fetches /api/business/hours on mount
  │   ├── Checks today's events from props or API
  │   ├── Runs priority cascade → picks CTA text + link
  │   └── Falls back to page override if provided
  └── ContextStrip (new client component)
      ├── Same API data as SmartCTAs (shared fetch)
      ├── 3-slot layout: status · kitchen · event
      └── Auto-refreshes every 5 min (status can change)

SmartCTAs and ContextStrip are client components that share a single API call. The rest of HeroWrapper stays server-rendered. Initial render shows generic CTAs, then hydrates with live data — no layout shift.
