# Data Model

## No local database

This site has **no Supabase, no Postgres, no Prisma, no migrations**. There is no `supabase/` directory and no ORM. All persistent data — customers, bookings, events, menus, hours, parking, reviews — lives in the paired management app at `management.orangejelly.co.uk`, which owns its own Supabase database.

The only "data" stored in this repo is **static content** (page copy, JSON-LD, public images, the SSOT JSON at `SSOT.json`).

See [[overview]] for the architectural rationale.

## Critical operational rule (referenced by SSOT)

When `/business/hours` returns a `special_hours` row with `kitchen: null` or `is_kitchen_closed: true`, food and Sunday-lunch slots **must be returned empty**. Drinks slots are unaffected. Resolution lives in `lib/table-booking-service-windows.ts` and `lib/hours-utils.ts`. Use `??` (not `||`) when merging special vs. regular kitchen data — `null` is a deliberate signal, not absence.
