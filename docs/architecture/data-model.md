## Special hours override — critical rule

The management API returns `kitchen: null` to signal a deliberate kitchen closure, **not** a missing value. Always use `??` (not `||`) when resolving special vs regular kitchen hours. See `lib/hours-utils.ts` -> `isKitchenClosed()`.

| Field | Meaning |
|---|---|
| `kitchen: null` | Kitchen closed (deliberate signal — must use `??`, not `\|\|`) |
| `is_kitchen_closed: true` | Explicit closed flag (defence in depth) |
| `is_closed: true` | Full venue closure |
| `schedule_config: []` | Custom booking schedule for the date |
