## Notes

- `.env.example` is the canonical declared list; many runtime-used vars (Microsoft Graph, feature flags, debug toggles) are documented only in code. Add any new var here AND in `.env.example` to keep them in sync.
- `ANCHOR_API_KEY` must never appear in `NEXT_PUBLIC_*` form. Every `process.env.ANCHOR_API_KEY` reference is in a server-only file (route handler or `lib/api/client.ts`).
- The site does not use `STRIPE_*`, `OPENAI_*`, `ANTHROPIC_*`, `RESEND_*`, `TWILIO_*`, or `SUPABASE_*` envs. Those services live in the management app.
