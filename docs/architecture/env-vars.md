## Notes

- `NEXT_PUBLIC_*` variables are embedded into the client bundle at build time. Never put secrets in these.
- `ANCHOR_API_KEY` is the most security-critical variable — it grants full write access to the management API. Never expose it client-side.
- `ANCHOR_API_BASE_URL` is optional and defaults to production. Override in local dev if pointing at a local management app instance.
- Microsoft Graph variables are only needed if the Christmas enquiry email flow is active.
- `MS_PREVIEW_TOKEN` gates the Manager's Special preview page — if unset, the page is accessible in non-production environments only.
- Several `NEXT_PUBLIC_*_DEBUG` flags exist for development diagnostics — none should be set in production.
