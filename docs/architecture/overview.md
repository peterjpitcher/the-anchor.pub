# Overview

> Auto-generated by session-setup. Manual edits will be overwritten on next refresh.

The Anchor Pub Website (`OJ-The-Anchor.pub`) is the public-facing marketing and booking site for The Anchor in Stanwell Moor. It is a thin, SEO-optimised front end over a remote management API; **it has no local database of its own**. All persistent state — bookings, events, hours, menus, parking, reviews — lives in the paired `OJ-AnchorManagementTools` app and is reached over the wire at `management.orangejelly.co.uk`.

## Tech Stack

- **Framework:** Next.js 14 (App Router) · React · TypeScript
- **Styling:** Tailwind CSS · CVA (class-variance-authority) for component variants
- **Validation:** Zod 4
- **Hosting / DNS / Edge:** Vercel · Cloudflare (DNS + Turnstile)
- **Analytics:** Google Tag Manager · Microsoft Clarity · custom `/api/analytics` + `/api/web-vitals`
- **Payments (passthrough only):** PayPal SDK on the client; capture/create proxied through this app to the management API
- **Tests:** Jest (`tests/` and `__tests__/` colocated)

## Auth Model

- **Public users** are unauthenticated. There are no logins on this site.
- **Server-to-server auth** to the management API uses `ANCHOR_API_KEY` attached server-side as `X-API-Key` (or `Authorization: Bearer ...` for PayPal sub-routes).
- **Form submissions** that originate in the browser carry a Cloudflare **Turnstile** token. The server proxy revalidates the token via `lib/turnstile.ts` before calling upstream.
- **Middleware** (`middleware.ts`) handles canonicalisation (HTTPS, www, trailing-slash, blog `?page=1`) and security headers — no auth gating.
