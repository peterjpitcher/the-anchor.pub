## What this project is

A **customer-facing marketing and booking website** for The Anchor pub, Stanwell Moor. It has **no database of its own**. All persistent data lives in the paired management app at `management.orangejelly.co.uk`. This site communicates with that app via a REST API authenticated with a server-side `ANCHOR_API_KEY`.

## Auth model

This is a **public website with no user login**. Authentication is purely **API-key based**:

- `ANCHOR_API_KEY` is a server-side-only secret sent as a `Bearer` token in `Authorization` headers to the management API.
- Cloudflare Turnstile provides bot protection on public-facing forms.
- `middleware.ts` performs **no auth checks** — it handles: apex-to-www redirect, HTTPS enforcement, trailing-slash normalisation, blog ?page=1 redirect, and cache-control / security headers only.

## Canonical domain

`https://www.the-anchor.pub` — Cloudflare TLS must be "Full" or "Full (strict)". Never "Flexible" (causes redirect loops).
