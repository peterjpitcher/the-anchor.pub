## Project Summary

**The Anchor Pub** is a customer-facing marketing and booking website for a pub in Stanwell Moor, near Heathrow Airport. This is a **marketing-first, database-free** Next.js application that proxies all business operations through the Orange Jelly Management API.

### Key Characteristics

- **No database**: All data (hours, availability, bookings, events) lives in the management system
- **API-driven**: Every mutation goes through the management API via HTTP proxy routes
- **SEO-heavy**: 100+ pages targeting local Heathrow travel and hospitality keywords
- **Multi-feature**: Bookings, parking, events, private hire, blog, reviews, live sport tracking
- **Public with no auth**: No login system; all endpoints are unauthenticated or use API key auth server-side only

## Middleware

**File**: `middleware.ts` (project root)

### Responsibilities

1. Domain & HTTPS enforcement (apex → www, http → https)
2. Trailing slash normalization
3. Redirect routing via `lookupRedirect()` utility
4. Cache headers (immutable for static assets, no-store for API mutations)
5. Security headers (X-Content-Type-Options, X-Frame-Options, etc.)

### Redirect Flattening

The middleware flattens apex domain + content redirects into single 301 hops to avoid GSC "Redirect error" reports.

## Data Flow

```
User Browser
    │
    ├─→ Page Request → Middleware → App Router
    │
    ├─→ Form Submission → /api/* (proxy)
    │   └─→ Management API (POST/PUT/DELETE)
    │       └─→ Supabase (in management system)
    │           └─→ Response → Browser
    │
    └─→ Analytics → GTM, GA4, Meta Pixel, Clarity
```

**Key insight**: The website has **no direct database connection**. All business logic lives in the management system.
