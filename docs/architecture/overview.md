## Auth Model

This is a **public website with no user authentication**. There are no login pages or session management. Security is handled at the API proxy layer:

- **ANCHOR_API_KEY**: Server-side secret used by API routes to authenticate with the management API. Never exposed to the client.
- **Turnstile tokens**: Anti-spam verification on booking forms, validated server-side via `TURNSTILE_SECRET_KEY`.
- **MS_PREVIEW_TOKEN**: Preview access token for the Manager's Special feature.
