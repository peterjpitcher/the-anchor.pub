## Data Flow: Booking to Confirmation

```
User fills booking form
  ↓
Client submits POST /api/table-bookings/create
  ↓
Route handler validates API key, CAPTCHA
  ↓
Calls management.orangejelly.co.uk/api/table-bookings (POST)
  ↓
Management API validates + creates booking in Supabase
  ↓
Returns booking reference + payment token
  ↓
Client initiates PayPal payment via /api/table-bookings/paypal/create-order
  ↓
PayPal returns order ID
  ↓
User completes payment in PayPal iframe
  ↓
PayPal redirects to /api/booking/payment-return
  ↓
Route captures payment via /api/table-bookings/paypal/capture-order
  ↓
Management API marks booking as confirmed
  ↓
GTM fires booking_confirmed event
  ↓
Redirect to /booking-confirmation/[reference]
  ↓
Confirmation page loads booking details via GET /api/table-bookings/[reference]
  ↓
User sees confirmation message + booking details
```
