## Middleware

`middleware.ts` handles:
- Domain redirects (non-www to www, HTTPS enforcement)
- Trailing slash normalisation
- Blog pagination normalisation (`?page=1` to `/blog`)
- Legacy URL redirects (via `lib/middleware-redirects.ts`)
- Cache headers: `/api/business/hours` is `no-store`; other API routes get `s-maxage=60, stale-while-revalidate=300`

Excluded from middleware: `_next/static`, `_next/image`, `favicon.ico`.
