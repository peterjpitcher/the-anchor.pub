## Special Routing Patterns

### Dynamic Route Segments

- `[id]` — Booking reference, event ID, or parking booking ID
- `[slug]` — URL-friendly identifiers for drinks, blog articles
- `[terminal]` — Heathrow terminal identifier (T1–T5)
- `[...path]` — Catch-all for dynamic blog content

### Blog Content Proxy

- `/content/blog/[...path]` — Proxies to management API for dynamic blog content
- Allows blog articles to be managed centrally without hardcoding all URLs
