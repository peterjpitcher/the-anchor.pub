## Middleware (`middleware.ts`)

Applied to all paths except `_next/static`, `_next/image`, `favicon.ico`.

- Redirects apex domain to `www.the-anchor.pub` (301)
- Enforces HTTPS on production (301)
- Strips trailing slashes (301)
- Normalises `/blog?page=1` to `/blog` (301)
- Adds security headers: `X-Content-Type-Options`, `X-Frame-Options`, `X-XSS-Protection`, `Referrer-Policy`, `Permissions-Policy`
- Sets cache headers: immutable for static assets; `no-store` for `/api/business/hours`; `s-maxage=60, stale-while-revalidate=300` for other API routes
