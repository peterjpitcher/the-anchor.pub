## Summary

**This project has zero server actions.** There are no `'use server'` directives anywhere in the codebase.

All mutations go through Next.js API route handlers (`app/api/*/route.ts`), which proxy requests to the management API at `management.orangejelly.co.uk`. This is the correct pattern for this project because:

1. The website has no database of its own
2. All data lives in the management app (OJ-AnchorManagementTools)
3. API routes protect the `ANCHOR_API_KEY` server-side
4. API routes handle CORS, caching, and Turnstile verification
