# SERP Snapshots — The Anchor, 7 July 2026

**Capture method & limitation (read first).** No Google SERP was scraped (hard rule). Snapshots below were captured 2026-07-07 via the sandboxed WebSearch API available to this session. That API is **US-localised and not a UK Google SERP**: it returns organic-style result lists and an AI-generated summary, but no local pack, no PAA, no autocomplete, and no positions that can be treated as Google rankings. Fields that need a human-viewed UK Google SERP (local pack contents, PAA verbatim, AI Overview citations) are marked **unavailable — needs manual UK SERP check by owner**. Treat "top results" below as directional competitor/intent evidence only, never as ranking data. GSC data was not available this run (see tracking-evidence.md), so no first-party positions are quoted; the one position cited is from the June 2026 GSC-backed run and is dated as such.
